Setup Guide

  1. 설정 → 연결 → 기타 연결 설정 → 프라이빗 DNS
  2. 프라이빗 DNS 공급자 호스트 이름 선택
  3. 아래 주소 중 하나를 입력 후 저장

Primary Node

one.dns.onetwohour.com

Secondary Node

two.dns.onetwohour.com

💡 Windows 11 및 최신 Windows 10은 DoH (DNS over HTTPS) 사용을 권장합니다.

1. 암호화된 DNS (DoH) 설정
  1. 설정 → 네트워크 및 인터넷 → Wi-Fi/이더넷 → 하드웨어 속성
  2. DNS 서버 할당 [편집] 클릭
  3. 아래 정보를 입력하세요

Node 1

IPv4: 3.39.126.146

HTTPS: https://one.dns.onetwohour.com/dns-query

Node 2

IPv4: 15.165.111.52

HTTPS: https://two.dns.onetwohour.com/dns-query

2. 레거시 IP 설정 (구형 OS)

제어판 → 네트워크 및 공유 센터 → 어댑터 설정 변경 → 속성 → TCP/IPv4

기본 설정 DNS 3.39.126.146
보조 DNS 15.165.111.52
